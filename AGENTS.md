# obs-multisite

Agent-facing notes for this repository. Human documentation lives in `docs/`,
and the project's scope and design decisions in `PROJECT-SCOPE.md`. Known
faults, their root causes and the reasoning behind past fixes are in `BUGS.md` —
read it before changing playout, seeking or timing code.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `stageaudioworks/obs-multisite`, via the `gh`
CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each mapped to a label string of the same
name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, created lazily
when terms or decisions actually get resolved. See `docs/agents/domain.md`.
